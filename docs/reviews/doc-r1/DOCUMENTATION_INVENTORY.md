# DOC-R1 Documentation Inventory

Audit baseline: `0649068ebda54b0f57e8e8a14360fb7b723ab1f2`.

Status vocabulary: `CURRENT` means materially aligned with the current
implementation; `PARTIAL` means useful but incomplete; `STALE` means it makes
current-product claims that are no longer true; `HISTORICAL` means it is valid
only as a record of an earlier release; `GENERATED` means it should be
regenerated from source rather than edited manually.

## Classification notes

- `book/src/cli` is generated by `go run -tags gendocs ./cmd/landlock-genprof
  <output-directory>`. The source command tree is authoritative.
- `docs/adr`, `docs/rfc`, release notes, and roadmap files should not be
  deleted merely because they are old; they need explicit historical labels.
- `DEMO_B1_REPORT.md` is an external untracked artifact and was not inspected
  or included in this audit.

## Primary documentation risks

1. Users can follow a stale Workbench description instead of the canonical
   React Operations Center.
2. The Book's CLI reference is not synchronized with the actual Cobra tree.
3. Current Operations Center semantics are distributed through internal
   milestone documents rather than one user-facing guide.
4. Historical claims and current demonstrated capability are not consistently
   separated at document boundaries.
