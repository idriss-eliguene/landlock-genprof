# Navigation model

The sidebar is stable across the workspace. The active item is marked with
`aria-current=page`; environment scope remains above page content. Navigation
changes presentation only and never changes authorization or environment.

Primary order: Overview, Workloads, Observations, Proposals, History,
Attention, Governance. Workload inspection naturally leads to Observations;
completed evidence leads to Proposals; History and Attention provide audit and
action follow-up.
