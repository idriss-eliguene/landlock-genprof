# Jobs to be done

- When I connect to Kubernetes, I want to see cluster, identity, and
  namespace immediately so I do not operate on the wrong environment.
- When I inspect a workload, I want to observe actual behavior so policy is
  based on evidence rather than assumptions.
- When evidence is incomplete or unknown, I want that uncertainty explained
  so I do not make an unsafe governance decision.
- When I generate a proposal, I want its observation and evidence basis so I
  can audit the decision later.
- When authorization is absent, I want a safe explanation and next action,
  not a misleading empty or healthy state.
- I need to discover workloads, review observations and evidence, generate
  proposals, find attention items, inspect history, and govern deliberately.
