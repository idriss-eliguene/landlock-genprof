# Design system

Typography uses a clear page title, section/card headings, readable body,
muted secondary text, and monospace forensic text. Spacing uses consistent
gaps; controls are grouped in labelled fields and responsive grids.

Statuses are text plus color: healthy, completed, running, warning, unknown,
failed, and restricted. Primary actions are prominent; governance/destructive
actions are explicit; disabled actions include a reason. Selects, inputs,
buttons, disclosure panels, tables, and empty/restricted/error states are
semantic and keyboard reachable.
