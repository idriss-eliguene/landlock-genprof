# Component inventory

Conceptual boundaries in the current server-rendered UI include AppShell,
SidebarNavigation, EnvironmentPanel, ClusterSelector, IdentitySelector,
NamespaceSelector, ExplicitNamespaceInput, ConnectionStatus,
EnvironmentDetails, PageHeader, StatusBadge, Workload view, Observation
cards/details, EvidenceSummary, CapabilitySummary, Proposal view, Attention
items, Governance actions, EmptyState, RestrictedState, UnknownEvidenceState,
ErrorState, and GovernanceConflict.

The implementation remains lightweight and does not introduce a frontend
framework solely for styling.
